As above, So below II — Texture Prep

Trim · pad · resize · rename — everything downloads, nothing needs folder permissions
Why this exists. The workbench's direct-save needs the File System Access API, which Chrome does not expose to pages opened from disk (a file:// origin), so the picker silently does nothing. This page uses ordinary downloads instead and works in any browser. Drop your generated images in, and it will cut the flat backdrop, trim to the artwork, add even padding, resize, and rename to the exact filename RimWorld expects — then hand you a ZIP.
Unzip into: <mod folder>\Textures\Things\Building\Risers\
If you'd rather have the workbench save directly, serve it over http instead of opening the file: python -m http.server 8000 in the mod folder, then visit localhost:8000/Tools/TextureWorkbench.html.
