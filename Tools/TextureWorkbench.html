Always attach the reference image. Every card below carries the path to a real sprite from that riser's own host mod, already on your disk. Drag it into the Nano Banana chat with the prompt and say "match this art style exactly". This does more than any wording — the prompts describe the style, but the reference is what actually lands it.
RimWorld's own Core textures are packed and cannot be opened, so Vanilla Expanded art is used as the vanilla reference — VE is built to be indistinguishable from base game.
Family A — Dubwise (Bad Hygiene, Rimefeller, Rimatomics)
Every 1×1 network device in these three mods is the same sprite recoloured: a rounded square base plate filling the cell, a chunky grey machine body centred on it, a small green square, a dark red bar, a thick near-black outline on everything. The plate colour is the network's identity — charcoal for plumbing, near-black for oil, blue for cold water, dark red for steam, teal for coolant.
Family B — Vanilla / Vanilla Expanded (power, Chemfuel, Temperature, Luciferium)
Completely different: almost no outline at all. Flat colour blocks butt straight against each other, a lighter top band over a darker lower band, groups of thin horizontal lines for fins, and tiny accents (VTE's AC unit is two little triangles). Pipes are rounded-cap tubes with a soft vertical gradient and one coloured identity band.
How to use.
  1. Connect mod folder… and pick this mod's root — the folder containing About/ and Textures/ (named 50b4332c2547).
  2. Pick a slot, Copy reference path, Copy prompt, and give Nano Banana both together.
  3. Cut the backdrop out before saving — see below.
  4. Drag the result onto the slot — written straight into Textures/Things/Building/Risers/. Drop anywhere on the page to match many files by filename.
The backdrop has to come off before RimWorld sees it. Images generate on a flat solid colour because asking these models for an empty background makes them paint a fake one into the picture instead. That flat colour is not what ships: a PNG that still has it will render as a solid square in game, sitting over the floor.
  • Every prompt names one exact backdrop colour and forbids it appearing in the object, so a single select-by-colour or magic-wand pass lifts it cleanly.
  • Use the backdrop selector above to switch all prompts at once. Neutral mid-grey looks best for judging the art; chroma magenta keys out far more reliably, because these sprites are mostly grey and a grey backdrop shares tones with the object.
  • Slots flag NO ALPHA when a dropped file is fully opaque — that is the backdrop still being there.
Rotation — three files, not four. Graphic_Multi.Init falls back to _east with westFlipped when _west is missing, which is exactly what DBH and VTE ship. Author _north _east _south only. VTE's ACUnit is the model: south = front face with its detail band; north = the back, nearly plain; east = side profile, the same colour blocks rearranged into vertical bands.
