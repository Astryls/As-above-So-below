As above, So below II — Riser Texture Workbench

Cross-level utility risers · one per network type · 15 buildings · 0 texture files
Not connected — previews and saving are disabled.
How to use.
  1. Click Connect mod folder… and pick this mod's root folder — the one containing About/ and Textures/ (folder name 50b4332c2547). Grant write permission.
  2. Copy a prompt into Nano Banana (Gemini image gen). Ask for a transparent PNG.
  3. Drag the result onto its slot — it is written straight to Textures/Things/Building/Risers/ under the exact filename RimWorld expects. Drop anywhere on the page to auto-match many files by name at once.
Saving needs the File System Access API (Chrome / Edge). In other browsers the page still works as a prompt reference and will offer a download with the correct filename instead.
Rotation. Risers marked rotatable ×4 are wall-mounted cabinets and need four files (_north _east _south _west) via Graphic_Multi — the mounting face must read correctly from every side, so the box sits against the wall edge with its cable run entering from the wall. Everything else is a floor pipe stub: rotation is meaningless for a vertical pipe, so it is one file via Graphic_Single and RimWorld derives the build-menu icon automatically.
