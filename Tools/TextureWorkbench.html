How to use.
  1. Click Connect mod folder… and pick this mod's root folder — the one containing About/ and Textures/ (folder name 50b4332c2547). Grant write permission.
  2. Every texture file has its own complete prompt. Click a slot tile to show its prompt, then Copy it into Nano Banana.
  3. Drag the result onto that slot — it is written straight to Textures/Things/Building/Risers/ under the exact filename RimWorld expects. Drop anywhere on the page to auto-match many files by name at once.
Saving needs the File System Access API (Chrome / Edge). Other browsers still get the prompts and will offer a download with the correct filename instead.
Rotation — four prompts, one per facing. Risers marked rotatable ×4 are wall-mounted cabinets using Graphic_Multi, so RimWorld needs _north _east _south _west as four separate images. Each has its own prompt describing that exact facing: which edge of the frame the wall runs along, whether you see the front panel or the rear brackets, and which side of the frame stays empty.
Tip: generate all four of a unit's views in one Nano Banana conversation, back to back — the model keeps colours and proportions consistent across a thread far better than across four fresh sessions. Each prompt already ends with an instruction to match its siblings.
