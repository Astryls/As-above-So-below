As above, So below II — Link Art & Approach Tagger

One grid square = one RimWorld tile. Drag a sprite to set its draw offset, resize it, and click a tile to set where pawns land.
Two jobs on one grid.
  • Overdraw — drag the sprite (or type numbers) to set that texture's draw offset, and set its draw size in cells. Both are per rotation. The dashed orange outline is the sprite's real alpha bounding box, measured off the PNG, so you can judge alignment against the tinted footprint instead of guessing.
  • Approach — click a tile in the ring around the footprint to say where a pawn is set down when it comes out of that link. Blue tile.
  • Blueprints and placement ghosts follow automatically — they are rebuilt from the built thing's graphicData at startup, and the exported XML writes both blocks anyway. You never tune them separately.
  • The west cards for the grand staircase and both ladders show east mirrored; there is no _west PNG and that is what RimWorld draws (Graphic_Multi.westFlipped).
  • Elevators are excluded — Graphic_Single, no open side.
  • When you're done: Export → paste it back and it gets baked into the defs in one pass.
